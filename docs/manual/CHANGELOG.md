# Documentation changelog

## 0.5.0 — 2026-11-12

- สร้างคู่มือระบบภาษาไทยสามภาค 24 บท พร้อมภาคผนวกและแผนภาพเวกเตอร์ต้นฉบับ.
- แยกสถานะโค้ด, automated tests, ผลทดสอบ Mac ที่ผู้ใช้รายงาน และสิ่งที่ยังไม่ได้ทดสอบจริง.
- บันทึกขั้นตอนติดตั้ง/ถอน Windows, macOS และ Ubuntu โดยอ้างอิง installer scripts ปัจจุบัน.
- ระบุข้อแตกต่างของ QR access token กับ room entitlement และข้อจำกัดของ Face AI/Agent.
- ระบุหลักฐานการ reboot และถอน Agent บน Mac ที่ผู้ใช้ส่งหลังคู่มือ Agent เดิมเขียนขึ้น.
